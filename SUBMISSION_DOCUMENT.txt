APPLICATION DESCRIPTION
================================================================================

The To-Do List Application is a web-based task management tool that leverages 
the JSONPlaceholder API to demonstrate real-world data fetching and DOM 
manipulation. The application allows users to:

1. View a list of all available users
2. Select a specific user from a dropdown menu
3. Automatically load and display that user's to-do items
4. See task statistics (total, completed, remaining)
5. Interact with tasks (mark as complete/incomplete)
6. Experience a modern, responsive user interface

================================================================================
TECHNICAL SPECIFICATIONS
================================================================================

ARCHITECTURE: Client-side web application (no backend required)
LANGUAGE: HTML5, CSS3, Vanilla JavaScript (ES6+)
API: JSONPlaceholder REST API
BROWSER COMPATIBILITY: Modern browsers (Chrome, Firefox, Safari, Edge)
RESPONSIVE DESIGN: Mobile-first, works on all screen sizes
EXTERNAL DEPENDENCIES: None (uses native browser APIs)

================================================================================
CORE FEATURES
================================================================================

1. USER SELECTION SYSTEM
   - Dropdown menu populated with all users from API
   - First user loads automatically on page initialization
   - Seamless user switching with real-time task updates

2. TASK MANAGEMENT
   - Displays all to-do items for selected user
   - Shows task title, completion status, and visual indicator
   - Interactive checkboxes to toggle task completion state

3. STATISTICS DASHBOARD
   - Total Tasks: Count of all tasks for the user
   - Completed: Number of finished tasks

4. USER INTERFACE

   - Clean, modern card-based layout
   - Smooth animations and hover effects
   - Clear visual distinction between pending and completed tasks
   - Color-coded status badges (Yellow: Pending, Green: Completed)

5. ERROR HANDLING
   - Graceful error messages if API calls fail
   - Loading indicators during data fetching
   - Fallback messages for empty task lists

================================================================================
API ENDPOINTS USED
================================================================================

1. Get All Users
   Endpoint: https://jsonplaceholder.typicode.com/users
   Method: GET
   Returns: Array of 10 user objects with details

2. Get User's To-Do Items
   Endpoint: https://jsonplaceholder.typicode.com/todos?userId={userId}
   Method: GET
   Parameter: userId (1-10)
   Returns: Array of to-do items for specified user

HOW THE APPLICATION WORKS
================================================================================

INITIALIZATION PROCESS:
1. Browser loads index.html
2. HTML loads styles.css and script.js
3. Page displays "Loading users..." in dropdown
4. JavaScript executes on DOMContentLoaded event
5. loadUsers() function fetches all users from API
6. Dropdown is populated with user names
7. First user (Leanne Graham) is automatically selected
8. loadTodos() function fetches that user's tasks
9. Tasks are displayed with statistics
10. Application is ready for user interaction

USER INTERACTION FLOW:
1. User clicks dropdown to select different user
2. Change event listener triggers
3. loadTodos() fetches new tasks for selected user
4. Previous tasks are cleared from display
5. New tasks are rendered with loading indicator during fetch
6. Statistics are updated for new user
7. User can check/uncheck task checkboxes
8. Task completion state updates visually
9. Statistics recalculate in real-time

================================================================================
CODE EXECUTION FLOW
================================================================================

MAIN FUNCTIONS:

1. loadUsers() - ASYNC
   - Fetches from https://jsonplaceholder.typicode.com/users
   - Parses JSON response
   - Iterates through users
   - Creates <option> elements for each user
   - Appends options to <select> element
   - Calls loadTodos() for first user

2. loadTodos(userId) - ASYNC
   - Sets currentUserId variable
   - Finds user object from users array
   - Updates page heading with user name
   - Shows "Loading..." message
   - Fetches from API: /todos?userId={userId}
   - Calls displayTodos() with fetched array
   - Calls updateStats() with same array

3. displayTodos(todos) - SYNCHRONOUS
   - Clears existing list items
   - Handles empty list case
   - Iterates through todos array
   - For each todo:
     * Creates <li> element
     * Creates checkbox input
     * Creates text span
     * Creates status badge
     * Appends all to list item
   - Adds event listener to checkbox

4. updateStats(todos) - SYNCHRONOUS
   - Counts completed tasks
   - Calculates total and remaining
   - Updates DOM elements:
     * totalTasks.textContent
     * completedTasks.textContent
     * remainingTasks.textContent
